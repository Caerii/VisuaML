# Paired routing interface

One trained router sees a registry of tool descriptions and two task-side descriptions. Each description has at most eight words drawn from the fixed vocabulary. A description encoder with shared weights scores each tool row. The learned relation network receives raw normalized feedback and threshold values plus the declared relation selector. It supplies a continuous mixture of the two task descriptions. The router uses the resulting scores to choose a numeric handle. Display names and handle values are excluded from learned features. Physical order has no positional features, and score ties resolve by the lowest handle. The first call uses a learned fixed query for the seed-transform family.

The task arrives already structured as seed, repeat count, threshold, relation, and two description strings. The host tokenizes those strings, admits exact program images, and supplies typed tensors. The graph builds arguments from live feedback or the initial seed. Argument copying and schema validation are deterministic in this variant. Numeric copying and selection measure different things. No threshold comparison or expected route is present in validation.

Each registry entry includes a signed nonnegative 64-bit handle, a description, four argument bounds, a validated executor program, and a fuel limit. Valid examples use three tools and unique handles. Missing or duplicate handles and out-of-schema requests are rejected before tool execution. Statuses are success (0), invalid (1), unavailable (2), and exhausted (3). Status other than success ends the bounded two-call computation. The raw executor result, reported feedback, source trace, and candidate scores are observable. Diagnostic overrides can change first feedback or force the second handle while leaving validation and tool execution in the graph.

The training distribution consists of 7,200 matched contexts, each with a below-threshold and an at-or-above-threshold value, plus two comparison polarities and shuffled rows. Families and vocabulary appear in training. Program images are absent from training. This is a learned structured inspection point, with distinct scope from the controlled-English autoregressive model or an open-language parser.
