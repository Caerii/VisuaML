# Locked paired-world protocol

The checkpoint controller and inference graph are unchanged from `72f5353`. The two published Signal Relay scenes are calibration fixtures and are excluded. The exploratory seed is 12119, with two pairs per family. The confirmatory seed is 48151, with 25 pairs per family. The confirmatory generator uses the same validity constraints and no model outputs to generate worlds.

Four related radius-one layouts use the frozen Signal Relay rule. Straight, elbow, and branched approaches add one hidden seed bit to change the arrival from the tick after the requested horizon to precisely that horizon. The blocked-ingress family changes one wall and adds two ticks to the path in its slower member. Policy ordering and horizons vary on a fixed design. The model sees identical text between the two members of each pair. It receives the actual first tool result, the paired world's substituted bit, or the corresponding control.

The primary success criterion counts a world pair only when both actual runs emit the intended follow-up tool after the correct first request and forecast. The crossed criterion requires both actual and both substituted decisions. The substituted decision is scored against the received bit. End-to-end success additionally includes argument, second-tool, and final-answer checks. Disabled, missing, and short-halo controls score the explicit stop behavior separately from task completion. All assigned cases stay in the respective denominators. Free paraphrases use the unchanged vocabulary admission procedure. A rejection at this boundary is an assigned failure recorded at event zero.

Regional forecasts are audited against an independent scalar transition at every cell and tick and against the full-world target and its remaining dependence cone. Report execution mismatches separately. The primary interval uses the world pair as its unit. It describes this generated mixture, with four fixed layout families, and does not estimate performance on an unseen physical rule or a new training seed. Deterministic policy references implement the explicitly stated bit-to-tool mapping. No learned weights or tool semantics change during the evaluation.
