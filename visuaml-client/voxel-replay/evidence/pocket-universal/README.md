## Construction

This is a finite-table interpreter for an extended Wang-style binary tape language, inspired by Hao Wang's *A Variant to Turing's Theory of Computing Machines* (1957). The table is generated by the readable scans and local rewrites in [build_universal_table.py](../../tools/build_universal_table.py).

- `L` and `R` move the simulated head. `M` and `E` write 1 and 0 respectively. `J n` jumps to instruction `n` on a 1 and falls through on a 0. `G n` jumps unconditionally. `H` halts.
- Encode `#`, followed by records `; marker opcode operand`, then `|` and the binary tape. The first marker is `*` and the others are `-`. The operand is present only for jumps and consists of `n` unary `u` symbols for a zero-based target `n`. Input cell 0 starts marked `a` or `b` according to its binary value. Physical blanks `_` following the input also decode as 0. An example prefix is `#;*Juu;-H;-R;-M;-H|b000`.
- At a simulated boundary, the universal head is at `#` in state `boundary`. Count separators to `*` to recover the simulated program counter. After `|`, `a` and `b` mark the head and decode as 0 and 1. In state `halt` the markers still describe the final configuration.
- The finite control finds the active record, carries its opcode to the simulated head, and makes the selected local rewrite. For a jump it flags the origin with `!`, sets a destination cursor `@` on the first separator, and advances that cursor once per operand symbol while changing `u` to `v`. It restores the operand symbols, clears `!`, activates the cursor's record, and returns to `#`. The two cursor tracks occupy separate cells, including when the destination equals the origin. Each scan terminates in a well-formed input, and the finite unary operand decreases in unmarked symbols once per jump iteration.

To simulate a deterministic one-way binary Turing machine, assign a label to each control state. At that label use `J` to dispatch on the read bit. Each arm writes the specified bit, moves as needed, and uses `G` to enter the next state's label. A terminal arm executes `H`. For a stay transition the arm omits the movement instruction. The binary one-way model is universal by standard tape coding. In particular, a finite alphabet can be encoded in fixed-width bit blocks and a two-sided tape folded onto tracks on a one-way tape, with finite control selecting the appropriate track. This yields a finite encoded program for any given simulated machine. The fixed interpreter implements each binary instruction and reestablishes the boundary invariant, so induction establishes simulation for every finite prefix.

The abstract construction uses an extensible tape to the right. Moving onto a fresh `_` produces a marked blank in place, with no fixed right sentinel in the table. Well-formed programs stay at or to the right of cell 0. The playable instance uses one 64 KiB WASM page and includes 24 extra blank cells. The editor bounds program length and input size. The UI and offline replay separately allow 4,096 universal transitions per session, and the replay gives the frozen graph 2,000 WASM fuel units per universal transition. Each experiment is a bounded run of the construction.

## Try it

From `visuaml-client/voxel-replay` run `npm ci` and `npm run dev -- --port 4180`. Open [Universal Tape](http://localhost:4180/pocket-universal.html). **Step universal machine** executes one table transition. **Step simulated machine** continues to the next decoded boundary or stop. The encoded tape follows the universal head, and the simulated view holds the last completed configuration. The browser runs linked WASM and checks the selected examples against saved VisuaML pages. Custom programs can be typed into the editor and encoded on reset.

```sh
export PYTHONPATH=.:../backend OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
python tools/build_universal_table.py
python tools/replay_pocket_universal.py
npm test
```
